# Security Hardening & Ethereum Blockchain Remediation Changelog

## Summary of Findings Resolved (F-01 through F-15)

| Finding | Resolution Implemented |
| :--- | :--- |
| **F-01** Account takeover via ID-only login | Removed `isDemoCardQuickLogin` and bill-only bypass from `POST /api/auth/login`. Enforced `scrypt` password verification, 8-char one-time Patient Access Codes (72h TTL, single-use, forced password setup), per-IP + per-identifier rate limiting, and isolated demo login behind `DEMO_MODE=true`. |
| **F-02** Unauthenticated patient/bill/QR PII disclosure | Protected `/api/auth/users`, `/api/reception/patients`, `/api/reception/patients/:id/bill-pdf`, `/api/reception/inquiries`, `/api/qr/:id`, and `/api/blockchain/stats` with `authenticate` & explicit `authorizeRoles`. Stripped all patient PII & clinical metadata from anonymous `GET /api/verify/:reportId` responses. |
| **F-03** Public file corruption endpoint | Permanently removed `POST /api/verify/tamper-file/:reportId`. Added `DEMO_MODE`-only, Admin-authenticated non-destructive in-memory tamper simulation (`simulate-tamper` / `reset-tamper`) that never mutates files on disk. |
| **F-04** Broken role boundaries & implicit Admin bypass | Removed implicit Admin bypass from `authorizeRoles`. Centralized `utils/access.js`. Denied `Receptionist` across all clinical report, timeline, search, prescription, QR, and share endpoints (`403`). Restricted deletion to Admin-only soft-delete requiring a documented reason while preserving encrypted files & ledger blocks. |
| **F-05** Plain-text passwords & static crypto fallbacks | Replaced plain-text credentials with `crypto.scryptSync` + `timingSafeEqual` (`utils/passwords.js`), stripped all secret hashes from API responses, added `config.js` fail-closed secret validation (`npm run setup`), and upgraded file storage to authenticated **AES-256-GCM v2** (`utils/cryptoUtils.js` + `scripts/migrate-encryption.js`). |
| **F-06** Empty medicines inventing Paracetamol | Strict validation in `POST /api/prescriptions` rejects missing/empty/malformed medicine arrays (`400`) and removes all invented defaults from records and PDFs. |
| **F-07** Duplicate detection mismatch (source vs generated PDF) | Stored both `sourceHash` (raw uploaded bytes) and `reportHash` (stored PDF bytes), checked duplicates against both across DB/ledger/on-chain before OCR, and guarded concurrent uploads with an in-flight lock set. |
| **F-08** Unsupported normal/NABH/certified claims | Removed all fabricated baseline parameters and ISO/NABH certification strings from `utils/aiSummarizer.js` and `utils/pdfGenerator.js`. Added mandatory clinical review disclaimer, `clinicianReviewed: false` default, and gated external Gemini behind `AI_EXTERNAL_PROCESSING=true` with de-identified pseudonyms. |
| **F-09** Local ledger vs Solidity contract | Wired `contracts/SITStudentsHospitalLedger.sol` via `solc` compiler & deployment script (`scripts/deploy-contract.js` / `npm run deploy:blockchain`) and live `ethers` v6 client (`blockchain/ethereumClient.js`) for Ethereum Sepolia Testnet anchoring & verification, with transparent fallback status reporting when unconfigured. |
| **F-10** Unvalidated lab order completion | Enforced strict `labRequestId` existence, patient ownership, and `PENDING_UPLOAD` checks; removed implicit auto-completion of unrelated pending orders. |
| **F-11** Extension-only upload & unbounded OCR/memory | Added magic-byte file signature verification (`utils/fileValidation.js`), strict MIME+extension filtering (`middleware/uploadMiddleware.js`), `1mb` JSON limit, upload rate limits, and `ConcurrencySemaphore` bounding concurrent OCR/PDF work. |
| **F-12** Fragile JSON persistence & destructive restore | Added atomic temp-file + rename persistence with 5 rolling `.bak` backups (`utils/atomicWrite.js`), backup recovery on startup, and non-destructive `restoreSimulatedTampering()` that never invokes `db.seedInitialData()`. |
| **F-13** Query-string Bearer tokens & missing share revocation | Rejected `?token=` in `authenticate`, migrated all protected PDF previews/downloads to Bearer-header `fetch` -> `Blob`, removed PII from share JWTs, enforced `1..1440` min bounds, set `Referrer-Policy: no-referrer`, and added `GET /api/share` & `POST /api/share/:jti/revoke`. |
| **F-14** Missing automated tests & CI | Implemented comprehensive `tests/api.test.cjs` (`npm test` using `node --test`) and `.github/workflows/test.yml` with isolated temporary storage fixtures. |
| **F-15** Missing Doctor prescription document upload | Added `POST /api/prescriptions/upload` and `GET /api/prescriptions/:prescriptionId/attachment` with magic-byte validation, AES-256-GCM encryption, SHA-256 verification, RBAC scoping, and Doctor UI upload controls. |
